项目背景（60 秒版）

AgentDesk：面向跨境电商独立站的 LLM Agent 服务平台——对外「客服工单 Agent」+ 对内「知识库问答助手」，共用一套底座（混合检索、工具治理、模型路由、评测与可观测）。

为什么不用豆包直接解决？——通用聊天机器人查不了自有订单库、写不了工单、 保证不了金额与订单系统一致、控不了权限。工具调用 + 业务数据一致性 + 分级审批，正是 Agent 的定义性场景（τ²-bench 同款）。所有设计决策均可翻到理论专著《深入理解AI Agent》的具体章节 （见仓库 docs/BOOK_MAP.md，60+ 条带节号对照）。
